# Predictive Maintenance for Vehicle Fleets using Machine Learning

**Internship:** Virtual Machine Learning Implementation Intern (YuvaIntern)
**Task:** Week 1 - Project Planning and Strategy Development

## Problem Statement
Fleet vehicles often break down unexpectedly because maintenance follows fixed intervals. This project plans a Python machine learning model that predicts whether a vehicle will fail within the next 14 days using sensor data, mileage and repair history.
